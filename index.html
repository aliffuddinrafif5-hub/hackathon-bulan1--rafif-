      Pitch deck

      Bakso Pak Slamet Digital

      Antrian dan biaya beres dari satu halaman.

      Masalah

      Antrian manual menimbulkan keributan. Harga ditentukan dengan perasaan. Daftar menu sulit diperbarui.

      Solusi

      Katalog digital, nomor antrian otomatis, kalkulator modal. Berjalan di HP biasa tanpa instalasi.

      Cara kerja

      Pembeli pilih menu, ambil nomor, tunggu dipanggil. Penjual memanggil satu per satu dan melihat untung.

      Pasar

      Jutaan pedagang kuliner kecil di Indonesia belum punya sistem pencatatan sederhana.

      Model bisnis

      Gratis untuk UMKM dasar. Paket tambahan: laporan harian, cetak struk, pembayaran QRIS.

      Rencana

      Uji coba 1 warung selama 1 bulan, perbaiki, lalu perluas ke pedagang sekitar.

      Pseudocode

      // Ambil nomor antrian
FUNGSI buatPesanan(nama, keranjang)
  JIKA keranjang kosong
    TAMPILKAN "Pilih menu dulu"
    KEMBALI
  nomor ← nomorTerakhir + 1
  total ← 0
  UNTUK setiap item DI keranjang
    total ← total + item.harga × item.jumlah
  SIMPAN pesanan(nomor, nama, total, "menunggu")
  TAMPILKAN nomor
AKHIR FUNGSI
      // Panggil berikutnya
FUNGSI panggilBerikutnya()
  JIKA ada pesanan "dilayani"
    ubah status → "selesai"
  p ← pesanan "menunggu" pertama
  JIKA p ada
    p.status ← "dilayani"
    TAMPILKAN p.nomor
  LAINNYA
    TAMPILKAN "Antrian kosong"
AKHIR FUNGSI

// Harga jual
FUNGSI hargaJual(bahan[], margin)
  hpp ← JUMLAH(bahan.harga × bahan.takaran)
  KEMBALI hpp × (1 + margin / 100)
